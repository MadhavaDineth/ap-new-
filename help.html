Getting started

The sidebar on the left is always visible, so you can move between screens at any point without losing your place. Reports and the admin panel only appear for administrator accounts.

  1. Dashboard

    Where you land after signing in: today's list, what is still pending, and how the month is going.

  2. Register appointment

    Creates a new booking and gives you the appointment number.

  3. Find appointment

    Looks up a booking by its number, shows the day diary, and sends reminders.

  4. Bills and receipts

    Adds up the charges, applies the pricing rule, and prints the receipt.

  5. Patients

    The patient list: add, edit, remove, and read a patient's treatment history.

  6. Reminders

    Every message the system has sent, newest first.

  7. Exit the system

    The button at the bottom of the sidebar signs you out safely.

Signing in

  1. Open the login page

    Go to the clinic website and press Staff login, top right.

  2. Enter your username and password

    These are issued by the administrator. Tick Remember my username on the front desk machine only.

  3. Press Sign in

    You land on the appointment screen. The session ends when the browser tab is closed.

⚠ Never share an account. Every record keeps the name of the person who created it, so a shared login makes the audit log useless.

Registering an appointment

  1. Take the patient details

    Full name, a 10 digit contact number and the address. All three are required.

  2. Choose the dentist and the treatment

    The estimated bill on the right updates as you choose, so you can quote the patient a price straight away.

  3. Pick a date and a free time slot

    Slots run from 8.30 a.m. to 6.30 p.m. in fifteen minute steps. Past dates are blocked.

  4. Press Save appointment

    The number, for example APT-1042, appears on a green confirmation panel. Write it on the patient card.

ⓘ Double booking is not possible. If that dentist already has a patient at that time, the system refuses the save and asks you to pick another slot.

Finding an appointment

  1. Search by number

    Type the appointment number and press Search. The full record opens below the box.

  2. Or browse the diary

    Filter by date, status or patient name, then click any row to open it.

  3. Update the status

    Use Mark confirmed when the patient calls to confirm, or Cancel appointment if they cannot make it.

Issuing a bill

  1. Load the appointment

    Enter the number on the billing screen and press Load.

  2. Check the charges

    The preview shows the treatment cost, the consultation fee, and the total.

  3. Choose the pricing

    Standard is the full price. Senior citizen takes 15% off the consultation fee, Insurance collects 80% of both charges from the patient, and Loyalty discount takes 10% off the treatment. The preview updates as you choose.

  4. Press Issue the bill

    The receipt is created and the appointment is marked as completed. The rule you picked is printed on the receipt.

  5. Print or save as PDF

    Press the print button and choose your printer, or Save as PDF to e-mail it to the patient.

⚠ Check the entitlement first. The system does not know who is a senior citizen or who is insured, so ask for the card before choosing anything other than Standard. The rule you pick is stored with the receipt and shows in the audit log.

Patient records

  1. Search first

    Type a name, phone number or part of an address. Booking an appointment already creates the patient, so most people are on file.

  2. Add or edit

    Use the form at the top. A contact number is 10 digits starting with 0, and it is what the system uses to recognise a returning patient.

  3. History

    History lists every visit that patient has had, newest first, with its status.

  4. Delete

    Only possible for a patient with no appointments. Anyone who has been seen stays on file so their visits and receipts still make sense — edit their details instead.

Reminders

  1. Sending one

    Open the visit on Find appointment and press Send reminder. Completed and cancelled visits cannot be reminded.

  2. The log

    The Reminders screen lists every confirmation, reminder, cancellation notice and receipt the system has sent.

ⓘ No mail server is connected yet. Messages are recorded in the log and printed to the server console rather than actually posted, so the patient still needs a phone call for anything urgent.

Reports and administration

These two screens are for administrator accounts only; they are hidden from the sidebar for everyone else.

  1. Reports

    The day's appointments, revenue between any two dates, the most common treatments, dentist workload and the top patients. Print puts the whole page on paper.

  2. Dentists and treatments

    Add new ones or change a price. Nothing is deleted: untick Active to retire a dentist or withdraw a treatment, and it stops being offered on the booking screen while old records keep working.

  3. Staff accounts

    Create an account, change a role, suspend someone, or set a new password. The system refuses to suspend or demote the last administrator.

  4. Audit log

    Who did what, and when — bookings, status changes, bills, reminders and every admin change.

Common problems

The Java server is not running, so the pages are using sample data kept in this browser. Nothing is being written to MySQL. Start the backend and reload:

  1. Start MySQL from the WAMP tray icon.
  2. Run the server class so it listens on port 8090.
  3. Reload this page. The yellow message disappears.

Check that Caps Lock is off, and that the username has no trailing space. If it still fails, the administrator can reset the password from the users table. Three failed attempts do not lock the account.

The lists are loaded from the dentists and treatments tables when the page opens. An empty list usually means the database connection failed. Check that MySQL is running and that the credentials in the configuration file are correct.

That dentist already has a patient booked at the same date and time. Choose the next free slot, or a different dentist. Cancelled appointments do not block a slot, so the time becomes available again as soon as one is cancelled.

Use the Print or save as PDF button on the receipt rather than the browser menu. It applies the print layout, which hides the sidebar, the buttons and the top bar, leaving only the receipt.

ⓘ Still stuck? Call the administrator on extension 12, or e-mail support@smilecare.lk with the appointment number and what you were doing when the problem happened.
